Dungeon-Crawler

Ein Dungeon Crawler für das Terminal, geschrieben in Python

Gebaut mit

  • Python
Code auf GitHub

Gleich hier ausprobieren

Eine Browser-Version des Spiels. Blau und Orange durchqueren einen frisch erzeugten Dungeon und treffen sich dann in der Arena. Das Spiel spielt sich selbst, bis du übernimmst.

@ Demo-KILP 20/20ANG 3VER 1LVL 1
* RivaleLP 20/20ANG 3VER 1LVL 1

Ein neuer Dungeon. Erst Beute, dann Monster, zuletzt die Arena.

Beide Seiten werden von der KI gespielt.

Jeder Durchlauf erzeugt einen neuen Dungeon, der das Terminalfenster ausfüllt. Eine Wand teilt die Karte: Eine Hälfte erkundest du, die andere ein KI-Rivale. Beide sammeln Ausrüstung, weichen Fallen aus und kämpfen gegen Monster, um aufzusteigen. Wer stärker ist, wenn ihr euch in der Arena in der Mitte trefft, gewinnt.

Begonnen hat es als Projekt an der FH. Seither verfeinere und erweitere ich es laufend.

  • Jedes Mal eine neue Karte

    Der Generator gräbt ein Labyrinth mit Räumen, offenen Flächen und einer Arena in der Mitte und passt alles an die Größe des Terminals an.

  • Ein Rivale mit Plan

    Der Gegner arbeitet in drei Phasen. Er sammelt Gegenstände, jagt dann Monster und geht schließlich in die Arena, um dich zu stellen.

  • Monster, die dich finden

    Monster streifen umher, bis du in ihre Reichweite kommst. Dann verfolgen sie dich auf dem kürzesten Weg, den sie per Breitensuche finden.

git clone https://github.com/LaJuMiRa/dungen-crawler.git
cd dungen-crawler
pip install readchar colorist
python3 dungeon.py

Braucht Python 3.10 oder neuer und ein Terminal mit mindestens 80 mal 30 Zeichen.
