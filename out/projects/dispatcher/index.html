Dispatcher

Ein Task-Dispatcher aus einfachen POSIX-Prozessen

Gebaut mit

  • C
  • POSIX
  • IPC
  • Linux
Code auf GitHub

Ein Elternprozess startet per fork einen Pool von Workern, verteilt Aufgaben über eine begrenzte Message Queue und wartet, bis jeder Worker seine Statistik gemeldet hat, bevor er aufräumt.

Kurz gefasst

  • Zwei Queues: eine für ausgehende Aufgaben, eine für zurückkommende Ergebnisse.
  • Jeder Worker beendet sich mit seiner eigenen Abschlussnachricht.
  • Eine C-Datei, gebaut mit einem einzigen Compiler-Aufruf.
